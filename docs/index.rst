Acestor Documentation
=====================

Welcome to the documentation for **Acestor**, a machine learning pipeline for dengue modeling and prediction.

Overview
--------

Acestor is a comprehensive package designed to run different disease models, with a focus on dengue fever forecasting and analysis at the district level across Indian states.
